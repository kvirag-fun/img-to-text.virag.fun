# 🖼️ Image to ASCII Converter

A fast, lightweight, and 100% client-side web tool that converts uploaded images into ASCII art text files (`.txt`). Built to be hosted directly on **GitHub Pages** with zero backend infrastructure.

---

## ✨ Features

* **100% Private & Local:** All image processing runs in the browser via the HTML5 Canvas API. No images are uploaded to any server.
* **Instant Text Export:** Download your generated ASCII art as a clean `.txt` file with one click.
* **Zero Dependencies:** Built with pure HTML, CSS, and vanilla JavaScript—no frameworks or build tools required.
* **Aspect Ratio Correction:** Automatic vertical scaling compensates for font dimensions so images don't look stretched.
